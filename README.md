# 🚀 Backend CLI Projects

A collection of beginner-friendly backend CLI projects built while learning Node.js.

These projects helped me practice:

- File handling with `fs`
- API requests using `axios`
- Terminal interaction with `readline`
- Async/Await
- JSON handling
- Error handling
- JavaScript logic building

---

# 📂 Projects Included

## 🌦️ Weather App

Fetches real-time weather data using a weather API.

### Concepts Used

- API handling
- Axios
- Async/Await
- Readline
- Error handling

---

## 📝 Todo App

A terminal-based Todo application with file storage.

### Features

- Add Todo
- View Todos
- Delete Todos
- Save data in JSON file

### Concepts Used

- File system (`fs`)
- JSON.parse()
- JSON.stringify()
- Readline
- Array methods

---

## ❓ Quiz App

A CLI quiz application that reads questions from a JSON file.

### Features

- Multiple choice questions
- Score tracking
- Final result display

### Concepts Used

- JSON handling
- Loops
- Conditions
- Readline
- Dynamic data rendering

---

## 💱 Currency Converter

Converts currencies using live exchange rates from an API.

### Concepts Used

- Axios
- APIs
- Async/Await
- Dynamic URLs
- Error handling

---
